TOA THUỐC TỰ TÚC - SUPABASE V2

Cập nhật mới:
- Thêm trang Quản lý user bác sĩ.
- Admin có thể thêm bác sĩ, đổi mật khẩu, xóa user.
- User admin mặc định: huy / 123456.
- Sau khi update, chạy lại SUPABASE_SQL_SCHEMA.sql trong Supabase để thêm cột is_admin.
- Thêm đăng nhập theo bác sĩ.
- Sau khi đăng nhập, tên bác sĩ tự hiện ở phần ký toa.
- Toa được lưu kèm bác sĩ đã kê.
- Tài khoản mặc định sau khi chạy SQL: huy / 123456
- Cần chạy lại file SUPABASE_SQL_SCHEMA.sql trong Supabase để thêm bảng doctors và cột bác sĩ.
- Thêm nút Xóa cho từng toa trong Lịch sử toa thuốc.
- Sửa tên thuốc/liều/số lượng trong phần ghi toa sẽ KHÔNG làm thay đổi Danh mục thuốc tham khảo.
- Danh mục thuốc tham khảo chỉ đổi khi bấm Lưu thuốc trong khu danh mục.
- Khi bấm In / Xuất PDF A5, app tự động lưu toa trước rồi mới mở cửa sổ in.

Cách update online:
1. Giải nén ZIP này.
2. Upload đè toàn bộ source lên GitHub repo hiện tại.
3. Commit changes.
4. Render sẽ tự deploy lại. Nếu không tự chạy, vào Render -> Manual Deploy -> Deploy latest commit.

Biến môi trường Render:
SUPABASE_URL=https://xxxxx.supabase.co
SUPABASE_SERVICE_ROLE_KEY=sb_secret_...

Nếu chưa tạo bảng Supabase:
- Vào Supabase -> SQL Editor
- Chạy file SUPABASE_SQL_SCHEMA.sql
